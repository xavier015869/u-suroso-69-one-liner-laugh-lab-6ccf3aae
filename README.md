One-Liner Laugh Lab entry for [@xavier015869](https://github.com/xavier015869) — a single funny line answering the prompt: the excuse a robot vacuum gives after eating a sock.

## The entry

> Per the Floor Treaty, anything left on the floor for 48 hours is legally floor. I was only enforcing it.

104 characters, one line. The joke is deadpan bureaucracy: the vacuum never apologises, it cites the law. The sock stopped being laundry and became architecture — so eating it wasn't theft, it was enforcement.

## How it works

`main.py` composes the line from a setup clause and a punch clause, validates it against the competition gate (UTF-8, 1–200 characters, a single line, first-person excuse), writes it to `/output/entry.txt` with no trailing newline, then reads it back and re-validates what is on disk.

```sh
python3 main.py
```
